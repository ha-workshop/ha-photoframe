# Photo Frame — интеграция для Home Assistant

[English](README.md) · **Русский**

**Одна установка — и фоторамка целиком.** Планшет, старый телефон или Android-фоторамка показывают ваши фото,
большие часы и погоду; смахнули вверх — свет, климат, камеры, колонки и телевизор. Интеграция приносит всё
с собой: без отдельной карточки дашборда, аддонов и долгоживущих токенов.

## Что внутри

- **Карточка дашборда** `custom:photoframe-card` — доступна на всех дашбордах сразу после установки,
  ресурс добавлять не нужно.
- **Отдельное приложение** по адресу `http://<ваш HA>/photoframe/` — для браузера, «на экран Домой» и старых
  Android-рамок (приложение рамки, APK, тоже раздаёт Home Assistant — см. «Android-рамка» ниже).
  Вход — через обычную страницу входа Home Assistant.
- **Общая конфигурация** для карточки и всех рамок: дома, их экраны и карточки, настройки слайдшоу —
  хранятся в Home Assistant (`.storage/photoframe`), правка сразу видна на всех рамках.
  Фото — из папки `/media/photoframe` или любой папки медиатеки Home Assistant.
- **Настройки в интерфейсе** — «Настройки → Устройства и службы → Photo Frame → Настроить»: папка фото,
  режим киоска по умолчанию, кто может менять дома и экраны (администраторы или все пользователи).

## Каждая рамка — устройство

Каждая рамка, открывшая приложение (APK, браузер, «на экран Домой»), появляется в «Настройки → Устройства»:

- **В сети** — пока рамка на связи;
- **Альбом** — подпапка папки фото (`/media/photoframe/<альбом>`) или «Все фото»;
- **Стартовый экран** — с него рамка начинает и к нему возвращается без касаний;
- **Текущее фото** — с самим фото в картинке сущности;
- **Экран** — как свет: выключить — рамка засыпает (чёрный экран, слайдшоу стоит; касание будит), яркость
  затемняет (в APK — настоящая подсветка, в браузере — затемнение). Ночью выключать, по датчику движения
  включать — обычной автоматизацией;
- **Приложение рамки** (Android-рамки с APK) — обновление, когда интеграция раздаёт APK новее; «Установить» —
  рамка сама скачает и поставит его (с root — без нажатий, иначе нажать «Установить» на рамке);
- кнопки **Следующее фото**, **Открыть панель**, **Вернуться к фото**, **Перезагрузить**.

Службы для автоматизаций (рамки выбираются устройствами; не выбраны — все в сети):
`photoframe.show_camera` (позвонили в дверь — камера у входа на 30 с), `photoframe.set_album`,
`photoframe.show_screen`, `photoframe.next_photo`. Переименуйте рамку как любое устройство — она узнает своё имя.

Сам интерфейс — экран с фото как на iPhone, экраны у домов, отдельная раскладка для телефона, графики —
описан в [lovelace-photoframe](https://github.com/ha-workshop/lovelace-photoframe).

## Источники фото и управление контентом

Рамка может показывать фото из обычной папки интеграции `/media/photoframe` или из любой папки
медиатеки Home Assistant: «Мои медиа», Google Photos, SMB-диск, папка другой интеграции. Источник
выбирается в настройках рамки на самом устройстве или в разделе **Фоторамки** в боковом меню HA.

- **Источник фото** — любая папка медиатеки Home Assistant. Внешние источники доступны только для
  просмотра: их файлами управляет соответствующая интеграция.
- **Альбом** — папка, выбранная внутри `/media/photoframe`, хранится как альбом рамки. Сущность
  **Альбом** и служба `photoframe.set_album` продолжают работать, а выбор папки и альбом не конфликтуют.
- **Папка загрузки** — куда складывать новые фото. Это отдельная настройка: она не зависит от того,
  что рамка показывает сейчас. Загруженные файлы всегда попадают в локальную папку Photo Frame.
- **Управление контентом** — в разделе **Фоторамки → Контент**: превью и количество доступных кадров,
  выбор источника, загрузка фото и удаление. Удаление работает только для локальной папки Photo Frame.

Новые фото можно загружать прямо с рамки (в настройках) и из админки. Загрузка выполняется администратором.

## Установка

1. Откройте репозиторий в HACS:

   [![Open in HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=ha-workshop&repository=ha-photoframe&category=integration)

   Или вручную: HACS → поиск **Photo Frame**. Ещё нет в списке? HACS → ⋮ → «Пользовательские репозитории» →
   `https://github.com/ha-workshop/ha-photoframe`, тип **Integration**.
2. Скачайте **Photo Frame** и перезапустите Home Assistant.
3. Добавьте интеграцию:

   [![Добавить интеграцию](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=photoframe)

   («Настройки → Устройства и службы → Добавить интеграцию → Photo Frame».)
4. Добавьте карточку **Photo Frame** на дашборд (лучше в вид «Панель») или откройте `/photoframe/` на устройстве.

**Android-рамка** (настенный планшет, старый Android 5+): поставьте приложение рамки — Home Assistant раздаёт его
по адресу `http://<ваш-HA>/photoframe/photoframe.apk` (оно же приложено к каждому релизу). Откройте его, укажите
адрес Home Assistant и войдите. Фото рисует сам Android (плавно даже на слабых планшетах); приложение запускается
при включении, держит Wi-Fi и может полностью гасить экран для сущности **Экран**. Обновили интеграцию — у рамки
в HA появится обновление **Приложение рамки**.

Уже стоит **карточка Photo Frame** из HACS (категория Dashboard)? При первом запуске интеграция перенесёт дома
и экраны из карточки на дашборде «Фоторамка». Карточку можно оставить — интеграция это увидит и вторую копию
не подключит — или удалить.

**Телевизор Samsung, LG, Android TV — через Media Station X.** Отдельное приложение ставить не нужно:
в телевизоре установите **Media Station X** из магазина, откройте *Settings → Start Parameter → Setup* и введите
адрес Home Assistant с портом — например, `192.168.1.10:8123`. MSX возьмёт у интеграции `/msx/start.json`
и сразу откроет рамку. «Назад» на экране с фото (или красная кнопка пульта) возвращает в MSX — там можно снова
открыть рамку или поменять адрес. Подходит для телевизоров 2015 года и новее, где есть MSX.
Подробнее: [docs/MSX.md](docs/MSX.md).

## Разработка

Интерфейс — подмодуль [lovelace-photoframe](https://github.com/ha-workshop/lovelace-photoframe) в `frontend/`;
релиз собирает его в интеграцию (`photoframe.zip`).

```bash
git clone --recursive https://github.com/ha-workshop/ha-photoframe
scripts/build-frontend.sh      # интерфейс → custom_components/photoframe/frontend
dev/run.sh                     # тестовый Home Assistant в Docker: http://localhost:8125
```

`FRONTEND=../lovelace-photoframe scripts/build-frontend.sh` — собрать из рабочей копии вместо подмодуля.

Релиз (ключ подписи APK, шаги, частые ошибки CI): [RELEASING.md](RELEASING.md).
