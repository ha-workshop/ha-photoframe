# Телевизор через Media Station X (MSX)

Отдельное приложение для телевизора собирать не нужно. [Media Station X](https://msx.benzac.de/info/)
(MSX) — бесплатное приложение из магазинов Samsung, LG и Android TV, которое показывает содержимое,
описанное обычным JSON. Интеграция Photo Frame отдаёт этот JSON и открывает в MSX нашу PWA.

Так рамка работает на Samsung 2015+ и других телевизорах, где есть MSX, без Tizen Studio,
сертификатов и пересборки приложения.

## Один раз на телевизоре

1. Установите **Media Station X** из магазина приложений телевизора.
2. Запустите MSX → **Settings → Start Parameter → Setup**.
3. Введите адрес Home Assistant вместе с портом, например `192.168.1.10:8123`
   (если HA открывается по HTTPS — включите в MSX замок безопасности).
4. Подтвердите. MSX загрузит `http://<адрес>/msx/start.json` и сразу откроет рамку.

Дальше MSX будет открывать рамку при каждом запуске. «Назад» на экране с фото (или красная кнопка
пульта) возвращает в MSX; там можно снова открыть рамку или поменять адрес сервера.

## Как это устроено

- `GET /msx/start.json` — стартовый объект. Отдаёт `content:http://{SERVER}/msx/content.json`;
  `{SERVER}` MSX подставляет сам.
- `GET /msx/content.json` — страница-мостик. У неё `action: link:http://<HA>/photoframe/?tv=1`:
  MSX выполняет его при старте и открывает рамку. После возврата стартовое действие не повторяется,
  на экране остаётся кнопка «Открыть рамку».
- `?tv=1` включает телевизионный режим в интерфейсе: «Назад» на экране с фото и красная кнопка
  возвращают в MSX через `history.go(1 - history.length)` — способ, который рекомендует MSX для
  внешних HTML5-приложений.

Оба адреса отдаются без входа в Home Assistant и с `Access-Control-Allow-Origin: *`: MSX загружает
JSON через fetch с другого origin. Ссылка на рамку собирается из адреса запроса, поэтому она всегда
ведёт на тот же сервер, который ввели в MSX.

## Если не работает

- **MSX показывает ошибку загрузки / status 0.** Проверьте, что HA открывается с телевизора по
  введённому адресу с портом и что в HA установлена эта версия интеграции. JSON должен отдаваться
  без авторизации: `curl http://<HA>:8123/msx/start.json`.
- **404 на `/msx/start.json`.** Интеграция старая — обновите её из HACS.
- **Открылась рамка, но «Назад» не возвращает.** На некоторых пультах «Назад» перехватывает сама
  MSX. Выйдите из MSX и запустите снова; красная кнопка пульта обрабатывается в интерфейсе, если
  MSX передаёт цветные кнопки загруженной странице.
- **Сервер MSX с путём, а не корнем.** MSX всегда ищет `/msx/start.json` от корня введённого
  адреса; если HA стоит за прокси с префиксом, используйте внешний адрес без префикса или
  сокращатель ссылок MSX.
